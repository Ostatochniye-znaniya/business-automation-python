# Границы модулей

Все ORM-модели регистрируются через app.db.base.register_models.
Внешние ключи заданы строками: модулям не нужны импорты чужих ORM-классов.
Dashboard получает данные исключительно через публичные методы сервисов.

Сервисы получают AsyncSession в конструкторе. Запись завершается commit внутри
use case, HTTP-слой не управляет SQL или транзакциями. При ошибке dependency
закрывает session и откатывает незавершённую транзакцию.

Провайдеры возвращают DTO с external_id. Преобразование внешних идентификаторов
во внутренние FK и синхронизация пока не реализованы. Mock providers служат
примером внешнего контракта, а не заполнением БД.

Поля и статусы Report предварительные. До согласования workflow методы записи
отчётов и результатов явно отклоняют вызовы. Неизвестная статистика — null;
это не нулевое количество и не признак завершённой проверки.
